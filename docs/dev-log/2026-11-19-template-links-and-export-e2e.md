# 2026-11-19 — 使い方からテンプレートへのリンクと、全テンプレートの出力E2E

- 影響: `/guide/`（使い方）の冒頭とフッターから`/templates/`（編み図のテンプレート）へ内部リンクを張った。#467で#481に含めず残していた内部リンクのうち、記号一覧（`/stitches/`）からのリンクは#482でページを追加した時点で本文・フッターともに入っていたため、今回の修正は使い方だけである。編集画面（`/`）のどこにリンクを置くかは利用者が決めておらず、#467の完了条件にも含まれないため入れず、issueへ残す。リンクの文言は`/chart-basics/`・`/stitches/`と同じ「すぐに使える模様は…テンプレートにまとめています」とし、既存の内部リンクと同じく`data-analytics`は付けない（測るのは編集画面とテンプレートのダウンロードへの導線で、静的なページ間の移動は計測しない）。iOS版の同梱の使い方には、Web版だけのページであるテンプレートへのリンクを置かない。
- 主なファイル: `public/guide/index.html`、`tests/e2e/templates.spec.ts`、`scripts/templates.test.mjs`
- テスト: `scripts/templates.test.mjs`で、使い方と記号一覧の両方から`/templates/`へリンクしていること、iOS版の使い方にはリンクしていないことを確かめる。`tests/e2e/templates.spec.ts`で、8種類すべての`.knit`を「バックアップから復元」で開き、編み図名（「（復元）」付き）と20段20目の盤面を1つのテストで順に確かめる。復元は編み図の切り替えを伴って出力パネルを閉じるため、閉じたことを確かめてからパネルを開き直し、PNGの署名と寸法（出力パネルに表示した寸法と実際のPNGの寸法の一致。寸法は記号の一覧を入れると使った記号の種類で変わるため、テンプレート間で同じであること自体は保証しない）、PDFの署名と盤面の描画命令（`pdfStreams`で全ストリームを展開して確かめる）を確かめる。ダウンロードは`downloadInsteadOfShare`で実際のダウンロードとして受け取る。8回の復元と16回の書き出しを行うため、このテストのタイムアウトは120秒に伸ばす。
- 検証: Node.js v26.8.1で、最初の変更時に`npm ci`、`npm run typecheck`、`npm test`（1180件成功）、`npm run build`、`npm run check:dist`（`dist verified: 3170.7 KiB`）、`npx vitest run scripts/templates.test.mjs scripts/guide-content.test.mjs scripts/static-page-analytics.test.mjs scripts/stitches-page.test.mjs`（65件）が成功した。Playwright E2Eの実行で新テストが全構成で失敗した（復元が出力パネルを閉じるのに、開いたままの前提で書かれていた）ため、パネルを復元のたびに開き直す形に直し、直後に`npm run typecheck`と`npx vitest run scripts/templates.test.mjs`（32件成功）が成功した。Playwright E2E（`npm run test:e2e`、Chromiumモバイル・デスクトップとWebKitモバイルの3構成）とiOS Simulator・Xcodeの検証はこの環境で実行できないため、リーダーが実行する。
