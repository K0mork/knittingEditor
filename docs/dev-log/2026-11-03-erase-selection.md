# 2026-11-03 — 範囲選択した部分の記号と線を一括で消せるようにする

- 影響: 範囲を選ぶと出る下の操作帯を「コピー｜保存｜消去｜キャンセル」にし、「消去」で選んだ範囲の記号と、範囲にかかる線をまとめて消せるようにした。これまでは消しゴムで1マスずつなぞるしかなかった。複数マスの記号は選択範囲が記号全体へ広がるので丸ごと消え、線は貼付と同じく、範囲の列を通り範囲の段に少しでもかかるものを丸ごと消す。1回の消去は「元に戻す」1回で戻り、確認は出さずに「選択範囲を消去しました」と通知する。消したあとは選択だけを外し、道具は「範囲」のままにして続けて別の範囲を選べるようにした。操作帯の「保存」とブロックパネルの「選択範囲をブロック保存」でブロックを保存したあとも、これまでの「描く」へ戻す動きをやめて同じく「範囲」のままにした。「キャンセル」も、選択だけを外して「範囲」のままにした（これまでは「描く」に戻した）。ブロックの貼付も、貼ったあとに「描く」へ戻さず貼付中のままにし、続けてタップすると同じ模様を何か所にも貼れるようにした。「やめる」で描画に戻る。貼付のたびに出る通知が盤面の下のほうに重なり、iPhoneの幅では次の貼付先のタップを受け止めて貼れなかったので、ボタンの無い通知と通知の地の部分はタップを素通りさせるようにした（`packages/editor-core/styles/base.css`。通知のボタンは今までどおり押せる）。消すものが無い範囲では「選択範囲に消すものがありません」と伝えて選択を残す。範囲を選んでいる間は、入力欄の外でDelete・Backspaceキーを押しても消せる（MacのDeleteキーはBackspaceとして届く）。モーダルのダイアログを開いている間と、修飾キー付きでは消さない。4つのボタンを幅390pxの画面で標準の文字のとき1行に収めるため、ほかのラベルも縮めた（「コピーして貼付」→「コピー」、「ブロック保存」→「保存」、「解除」→「キャンセル」）。「保存」は編み図の保存と紛れないよう、読み上げ名を「選択範囲をブロックに保存」、「消去」の読み上げ名を「選択範囲を消去」にした。使い方のページ（Web版・iOS版）も新しいラベル、消去、続けての貼付の説明に合わせた。消去の操作はGA4へ送らない。Web版とiOS版の両方に入る。
