# 2026-11-21 — iOS 1.2の提出に向けて版・メタデータ・審査メモを更新する

- 影響: `ios/project.yml`の`MARKETING_VERSION`を`1.1`から`1.2`にし、`CURRENT_PROJECT_VERSION`は`1`のまま、XcodeGenで`ios/knittingEditor.xcodeproj`を作り直した（変わったのは`MARKETING_VERSION`の2行だけ）。`ios/docs/APP_STORE_METADATA.md`は、#473の決定に従ってサブタイトルを「無料で編み図を作成・PDF印刷」、キーワードを現行に「編み方,靴下,ベスト,無料」を足したもの、プロモーションテキストの冒頭を「棒針編みの編み図を、iPhone・iPadで無料で作れます。登録は要りません。」に変え、「このバージョンの新機能」に`### 1.2`を足した。`ios/docs/APP_REVIEW_NOTES.md`は、1.2で増えた操作（PNG・PDFのクレジット、共有シートの文面、iPadのdeleteキー）を英語・日本語の「New in version 1.2」「バージョン1.2の変更点」に具体的な手順で書いた。4000文字に収めるため、前の版の変更点は消した（転記範囲は3873文字）。アプリの動作、Web版、Pagesの配信物は変えていない。無効化した機能やリモートの切り替えは入れていない（App Review Guidelines 2.5.19）。
- 主なファイル: `ios/project.yml`、`ios/knittingEditor.xcodeproj/project.pbxproj`、`ios/docs/APP_STORE_METADATA.md`、`ios/docs/APP_REVIEW_NOTES.md`
- テスト: 新しいテストは足していない。既存の`sh ios/scripts/check-app-store-docs.sh`、`node scripts/check-pr-smoke-ui-tests.mjs`、`npm test -- scripts/`で、文字数・製品名・節の有無・スモークテストの一覧・文書の検査を通した。
