# 2026-11-19 — 静的なページの同じタブへのリンクで`link_clicked`を確実に送る

- 影響: 静的なページ（`/guide/`・`/templates/`・`/stitches/`・`/chart-basics/`・`/support/`・`/privacy/`）で、同じタブで移るリンク（使い方の「編み図を作成する」など）を押したとき、gtag.jsがイベントをまとめて後で送る間にページが切り替わり、`link_clicked`が失われていた（#465で本番確認済み）。`public/analytics.js`を、同じタブで移るリンクではクリックの既定の動作を止め、`transport_type: 'beacon'`で送ってから、gtag.jsが送った後に呼ぶ`event_callback`で移動するようにした。コールバックが来なくても（gtag.jsが広告ブロックで止められる・読み込めない・失敗するときも）、短い猶予（`SAME_TAB_NAVIGATE_TIMEOUT_MS`＝500ミリ秒、`event_timeout`と同じ値）のあとに必ず1回だけ移動する。修飾キー（Ctrl・Cmd・Shift・Alt）、主以外のボタン、`target`による新しいタブ・別フレーム（`_self`は同じタブとして扱う）、`download`、既定の動作がすでに止められたクリックは移動しないため、従来どおりブラウザの既定の動作のまま送るだけにする。計測しない環境（`navigator.webdriver`、User-Agentの`Claude/`、オプトアウト、本番以外のドメイン）では`start()`が何も登録せず`false`を返すため、既定の動作を止めない。測定IDは`MEASUREMENT_ID`の一か所のままで、インラインのスクリプトは増やさずCSPの対象外になる書き方も使わない。`docs/ANALYTICS.md`の静的なページの節に同じ内容を書いた。
- 主なファイル: `public/analytics.js`、`src/staticPageAnalytics.test.ts`、`docs/ANALYTICS.md`
- テスト: `src/staticPageAnalytics.test.ts`を書き直した。同じタブのクリックで`link_clicked`に`transport_type: 'beacon'`・`event_callback`・`event_timeout`が付くこと、コールバックが来るまで移動しないこと、コールバックと猶予の両方が来ても移動が1回だけなこと、コールバックが来なくても猶予の時間で移動すること、`target="_self"`を同じタブとして扱うことを確かめる。修飾キー4種・主以外のボタン・`target="_blank"`・`download`のクリックで既定の動作が止まらず、beaconもコールバックも付けない送り方になること、すでに既定の動作が止められたクリックでは移動させないこと、オプトアウトでは何も送らず既定の動作も止めないことを確かめる。既存の測定ID・停止キーの一致と送信条件の表はそのまま残した。
- 検証: `node --version`はv26.8.1。`npm run typecheck`、`npm test`（1184件成功）、`npm run build`、`npm run check:dist`（dist verified）が成功し、`dist/analytics.js`が`public/analytics.js`と同じであることを確かめた。`npx vitest run src/staticPageAnalytics.test.ts`（13件成功）も実行した。Playwright E2E（`npm run test:e2e`）とiOS Simulator・Xcodeの検査はこの環境では動かせないため、リーダーが実行する。なお、既存のE2Eに静的なページの計測を確かめるspecはない（`tests/e2e/chart-basics.spec.ts`などは`navigator.webdriver`で計測が除外されたまま遷移を確かめている）。
- デプロイ影響: あり（Pagesへ配信される）。配信後に本番の`/guide/`で「編み図を作成する」を押したときの`link_clicked`（`link_name: editor`）がGA4 Realtimeに届くことを確かめる（#465の残りの完了条件。`link_name`はカスタムディメンションに登録済み）。
