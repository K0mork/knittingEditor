# 2026-10-09 — 端末の外観に合わせてダークモードで表示する

- 影響: 端末がダークモードのとき、Web版とiOS版の編集画面を暗い配色で表示するようにした（#116）。切り替えは端末の外観に従うだけで、アプリ内の設定は置いていない。共通CSS（`packages/editor-core/styles/base.css`）の色をカスタムプロパティにまとめ、`@media (prefers-color-scheme: dark)`でダーク用の値に差し替える。`:root`に`color-scheme: light dark`を指定し、入力欄やスクロールバーも外観に合わせる。ダークでは、ヘッダーは濃い緑、地・パネル・ダイアログ・ボタン・入力欄は暗い緑がかった灰色、文字は明るい色にした。選択中の枠・フォーカス・リンクは、暗い地との差が出るよう明るい緑にした（`--accent`・`--link`）。盤面のマスは編み図の背景色（#140）で描き、外観では変えない。既定の白い盤面は、ダークでも白のまま。暗くなるのは盤面の外側と段・目番号の帯だけで、`BoardCanvas`が共通CSSの`--canvas-*`を読み、外観が変わると描き直す。PNG・PDFは外観に左右されない。使い方（Web版・iOS版）、サポート、プライバシーポリシー、第三者ソフトウェアのライセンス（`scripts/third-party-notices.mjs`が生成）の各ページにもダーク用の配色を足した。ブラウザのツールバーの色（`theme-color`）は、ライトとダークで分けた。iOS版は、v1.0で入れた明るい配色の固定（`Info.plist`の`UIUserInterfaceStyle`=`Light`、#79）を外した。起動画面の色（`LaunchBackground`）にダーク用の濃い緑（`#1f4228`）を足し、準備中の表示と`WKWebView`の背景（`AppColors.editorPageBackground`）、準備中の表示の文字（`AppColors.editorSecondaryText`）を、ライト・ダークで共通CSSと同じ色にした。明るい配色の見た目は変えていない（補足の文字の色を`--hint-text`として分け、`#526059`のままにした）。
