# 2026-10-29 — Node.js 26 LTSへ移し、版の指定を`.node-version`にまとめる

- 影響: Issue #109。Node 26が2026-10-28にLTSになったため、開発とCIのNodeを24から26へ上げた。版はルートの`.node-version`（`26`）だけに書き、CIの`actions/setup-node`はすべて`node-version-file: .node-version`で読む。これまでNodeを設定していなかったmacOSのジョブ（`ci.yml`の`ios`、`ios-full.yml`の`ios_full`・`app_update`・`release_archive`）でも、Xcodeのビルドフェーズ（`ios/scripts/build-web.sh`）がnpmとViteを実行するため、同じ版を設定してログに`node --version`を出す。`build-web.sh`もビルドに使ったNodeの版をログに出す。`package.json`に`engines.node: ">=26 <27"`を足し、`@types/node`を26.6.5へ上げた。`.node-version`の変更でWeb・iOSの両方のCIと`Full iOS validation`が走るよう、変更範囲の判定とpathsに加えた。`smoke`のsparse checkout（cone mode）はルート直下のファイルを含むため、`.node-version`も取得される（手元のgitで確認）。
- 主なファイル: `.node-version`、`.github/workflows/ci.yml`、`.github/workflows/ios-full.yml`、`ios/scripts/build-web.sh`、`package.json`、`package-lock.json`、`AGENTS.md`、`README.md`、`ios/design/app-icon/README.md`
