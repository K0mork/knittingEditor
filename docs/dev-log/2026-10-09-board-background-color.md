# 2026-10-09 — 盤面の背景色を編み図ごとに選べるようにする

- 影響: 記号の色が盤面の地の色に近いと見えなくなる問題（#140）に対し、地の色（背景色）を利用者が選べるようにした。記号の形・太さ・色は地の色によって変えない。「盤面」パネルに「背景色」の欄を足し、白（`#ffffff`、既定）・グレー（`#808080`）・黒（`#1e1e1e`）のボタンと、自由に選ぶ色選択（「ほかの色を選ぶ」）を置いた。黒は真っ黒では暗すぎたので少し明るくした。色のついたプリセットは、見やすさが主に明るさの差で決まることと、毛糸の色と読み違えるおそれがあることから置かず、必要なら色選択で選ぶ。地の色は編み図ごとに記録（`ChartDocument.backgroundColor`、`#rrggbb`）へ入り、`.knit`にもそのまま入る。地の色を選んでいない既存の編み図と、この項目の無い`.knit`は白い地として読むので、移行は無い。`.knit`の形式名・版・記号カタログ版は変えていない。この項目を知らない古い版で新しい`.knit`を読み込むと、白い地で表示される。復元時、`#rrggbb`でない地の色は捨てて白い地として復元する。地の色の変更は盤面の編集と同じく自動保存するが、編み図名の変更と同じく元に戻す履歴には積まない。保存の書き込み中に色を変えても書き込み前の記録で古い色へ戻らないよう、編集セッションは地の色を記録とは別に持ち、保存するときに記録へ入れる。段ごとの縞と罫線の色は地の色から作り（`model/boardColors.ts`）、暗い地では地より明るい線にする。白い地では従来とほぼ同じ色になる（画面の罫線は`#c9cec7`→`#c9cecb`、`#7d8a83`→`#7d8982`、縞は`#f3f4f0`→`#f3f4f3`。PNG・PDFの罫線は従来と同じ）。PNG・PDFは選んだ地の色で出し、地の色は盤面のマスにだけ塗って、段・目番号の帯は白い紙のままにする。PDFは白い地では塗りの命令を足さず、罫線を灰色（`G`）ではなくRGB（`RG`）で指定するようにした。「白くする」は編み図の外を表す記号なので、どの地でも白のままにする。編み図一覧の縮小画像は、空いたマスを地の色で塗る。画面には説明文を置かず、Web版とiOS版の使い方ページの「3. 段数と列数を変更する」に、背景色で地の色を変えられることと、編み図ごとに保存されPNG・PDFにも出ることを書いた。Web版とiOS版の両方に入る。
