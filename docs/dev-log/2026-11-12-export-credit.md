# 2026-11-12 — PNG・PDFにサイト名・URL・QRコードのクレジットを入れる

- 影響: 出力したPNGとPDFに、サイト名「棒針編み図エディタ」・URL `https://knittingeditor.com/`・そのURLのQRコードを、控えめに入れるようにした。出力パネルに「クレジットを入れる（サイト名・URL・QRコード）」の切り替えを足し、既定で入れる。外すとこれまでと同じ出力になる。PNGは下端に白い帯を作り、左にサイト名とURL、右にQRを置く。QRの大きさは画像の幅の15%を目安に最小99px・最大231pxの範囲で、一辺をモジュール数（33）の倍数に丸めて各モジュールを整数ピクセルで描く。解像度が上がっても小さくならない。小さい画像でもサイト名とQRが収まるよう、クレジットを入れるときは画像の幅を最低384pxにする。PDFは下端のフッターに同じ内容を入れ、1ページ版とA4分割版のどちらにも入れる。分割版では、ページ範囲の表示と並べて置く。フッターの高さは70pt、QRは46pt（約16mm）で、QRの下端・右端はページ余白（24pt）の内側に置き、A4に印刷して読み取れる大きさにした。QRは端末内で作る（`uqr` 0.1.3、MIT。外部の生成サービスへURLを送らない）。PDFは矩形だけで描き、画像は埋め込まない。クレジットを入れると、PNGは帯のぶん画像が縦に伸び、PDFは盤面が少し小さくなる。編み図の内容は変えない。
- 主なファイル: `packages/editor-core/export/credit.ts`（新規）、`packages/editor-core/export/exporters.ts`、`packages/editor-core/export/pdfLayout.ts`、`packages/editor-core/export/pdf.worker.ts`、`packages/editor-core/export/annotations.ts`、`packages/editor-core/ui/ExportControls.tsx`、`package.json`・`package-lock.json`（`uqr`）、`public/guide/index.html`・`ios/Web/public/guide/index.html`（同じ段落）、`public/llms.txt`、`scripts/check-dist.mjs`・`ios/scripts/check-app-bundle.sh`（第三者表記に`uqr`を追加し、クレジットのURLだけを表示用の文字列として除外）・`ios/Tests/KnittingEditorAppTests/LocalWebSchemeHandlerTests.swift`・`ios/docs/APP_STORE_METADATA.md`（第三者表記に`uqr`を追加）
- テスト: `credit.test.ts`で、URLとサイト名、QRの大きさ・余白・位置検出パターン・再現性を確かめる。`exporters.credit.test.ts`で、クレジットの有無によるPNGの高さの差、白い帯と区切り線、QRが右端の範囲にだけ描かれること、サイト名とURLの位置、オフのときに出ないことを確かめる。`pdf.worker.test.ts`で、フッターの高さ、サイト名（日本語フォント）・URL・QRの矩形、画像を埋め込まないこと、オフのときに出ないことを確かめる。`pdfLayout.test.ts`で、クレジットのぶん1ページに入る段数が減ることを確かめる。`ExportControls`のテストを、切り替えが2つになったことと、既定で`includeCredit: true`が両方の出力へ渡ることに合わせた。既存のE2Eは、クレジットのフッターで1ページに収まる段数が変わったため、`editor.spec.ts`の「ちょうど1ページに収まる」盤面を53段から50段へ直し、太線を確かめるテストのPNGの寸法を帯のぶん（600×648px→600×756px）に直した。`tests/e2e/export-credit.spec.ts`で、既定で入っていること、外すとPNGが低くなること、表示の寸法が実際のPNGと一致することを確かめる。レビュー後、`credit.test.ts`でQRの余白4モジュールを、`exporters.test.ts`でクレジット込みの既定セルサイズ（700×100）を、`pdf.worker.test.ts`で1ページ版と分割版の全ページ（一覧だけのページを含む）のQRの位置・URLを、`exporters.credit.test.ts`でPNGのQRが白い帯の右下にありモジュールが整数ピクセルであることを確かめる。E2Eは、クレジットのフッター70ptで1ページに収まる盤面を49段×37目へ直し、PNGの寸法を600×767pxへ直した。
