# 2026-10-20 — 保存・復元UIテストの効かなかったタップだけ押し直し、失敗の記録を残す

- 影響: `testBlockSaveAndFullBackupRestoreFollowGuide` の断続的な失敗への対処。iPhoneでは「Browse」から保存場所の一覧へ戻る途中のタップが効かず、一覧に残ったため、保存場所の静止を待ってから押す。バックアップのセルが10秒で押せず、保存場所がまだ画面内で押せる場合だけ画面写真を添付し、静止を待って1回押し直す。最後は残り20秒待ち、選べなければ従来のメッセージで失敗する。iPadでは盤面の静止後でも描画のタップが効かず記号数が変わらなかったため、冒頭の3マスの描画だけ、10秒で増えず元の記号数の盤面がある場合に画面写真を添付し、再度静止を確かめて1回押し直す。最後の記号数の確認は従来どおりとし、他のテストのタップは変えない。iOS全検証ではxcresultとxcodebuildのログを生成し、再試行で成功した場合を含めテストケースの失敗行がある場合、またはジョブが失敗した場合に、端末別・実行試行別のアーティファクトとして7日間保存する。`tee`を使い、`pipefail`でテスト失敗の終了コードを保持する。
- 主なファイル: `ios/UITests/KnittingEditorUITests/KnittingEditorUITests.swift`、`.github/workflows/ios-full.yml`
- テスト: `testBlockSaveAndFullBackupRestoreFollowGuide` の描画ループと復元の保存場所選択ヘルパーを更新。各押し直しは効いていないと確認できる場合だけ1回に限定し、押し直しても進まなければ失敗する。
- 検証: `git diff --check`、`node scripts/check-pr-smoke-ui-tests.mjs`（既存11件）、`ruby -ryaml -e 'YAML.load_file(".github/workflows/ios-full.yml")'`、`xcodegen generate --spec ios/project.yml` が成功。YAMLから実行スクリプトを一時ファイルに抽出し、`bash -n /tmp/ke-flake-run.sh /tmp/ke-flake-test_failures.sh` が成功。`python3 /tmp/ke-flake-check-workflow.py` で成功のみ・初回失敗後に成功・失敗のログを両端末名で判定し、失敗の検出、アーティファクト名用の端末名の変換、`pipefail`による終了コードの保持を確認した。`xcrun simctl list devices available` はCoreSimulatorServiceへの接続制限で失敗。`xcodebuild build-for-testing -project ios/knittingEditor.xcodeproj -scheme knittingEditor -destination 'platform=iOS Simulator,name=KE verify iPad' CODE_SIGNING_ALLOWED=NO -derivedDataPath /tmp/ke-dd-flake` は同じ接続制限により対象Simulatorを取得できず、ビルドを検証できなかった。Simulatorでのテストとブランチでの `ios-full.yml` は指示に従い未実行で、結果はPRに記録する。
- デプロイ影響: なし。iOSのテストとiOS全検証のワークフローだけで、Pagesの配信物は変わらない。ブランチの全検証で両端末の動作と失敗時の成果物保存を確認する。
