# 2026-11-06 — iOS 1.1を提出し、審査待ちにする

- 影響: 利用者の報告により2026-11-06にv1.0が公開されたあと、審査中に`main`へ入った変更をv1.1として提出した。v1.1には、範囲選択の「消去」「保存」、続けて貼れるブロック、さらに大きな文字への対応、iCloud Driveのダウンロード失敗の案内が入る。2026-11-06 22:23（JST）に1.1 (1)をApp Store Connectへ提出し、審査待ちになった。
- 主なファイル: `ios/docs/RELEASE_VERIFICATION_RECORDS.md`、`ios/docs/RELEASE_RUNBOOK.md`、`ios/docs/APP_STORE_CHECKLIST.md`、`ios/docs/APP_STORE_METADATA.md`（アプリのコードは変えていない。版は#427で`ios/project.yml`の`MARKETING_VERSION`を`1.1`にした）
- テスト: 新しいテストは足していない。提出する文書の検査は`ios/scripts/check-app-store-docs.sh`（審査メモの転記範囲が3,848/4,000文字で収まること）と`ios/scripts/check-release-assets.sh`（アプリ同梱の資産とオフライン参照）で行った。
- 検証:
  - 提出元は`main`の`1fc015f`。`CI and deploy Pages`のrun [42214015767](https://github.com/K0mork/knittingEditor/actions/runs/42214015767)（`ci-gate`・`deploy`・`smoke`）と、`Full iOS validation`のrun [42214015686](https://github.com/K0mork/knittingEditor/actions/runs/42214015686)（iPhone 17・iPad (A16)の全テスト、両端末のapp_update、release_archive）が成功した。
  - Xcode 27.2（`27B52`）のReleaseで`xcodebuild archive`を実行し、`ios/scripts/check-release-assets.sh`が成功した。アーカイブのアプリは`CFBundleShortVersionString=1.1`、`CFBundleVersion=1`、`DTSDKName=iphoneos27.2`、`DTXcodeBuild=27B52`。
  - `xcodebuild -exportArchive`でApple Distributionに再署名し、`Manage Version and Build Number`を有効にしてApp Store Connectへアップロードした。処理完了のメールを受け取り、App Store Connectで1.1 (1)を選んで提出した（審査待ち）。
  - 審査メモは、見出しの記号を外して箇条書き・番号・空行を保った3,810文字の文面を貼った。転記範囲の検査は3,848/4,000文字で成功した。
  - タグ`ios-v1.1-build1`を`1fc015f`に付けてpushした。
  - ローカルの`npm test`・`npm run build`・`npm run test:e2e`は、Webと共有コードを変えていないため実行していない。アプリのコードも変えていないので、提出元の`1fc015f`のPR CIとFull iOS validationの結果を使う。このPRでは`sh ios/scripts/check-app-store-docs.sh`と`npx vitest run scripts/app-privacy-docs.test.mjs`を実行する。
- デプロイ影響: App Storeの更新のみ。Pagesの配信内容は変わらない。残りはTestFlightで1.1 (1)をiPhone・iPadの実機で確認し、承認後に公開して、App Storeの製品ページと公開版の主要フローを確かめること。
