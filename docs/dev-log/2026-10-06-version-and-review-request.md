# 2026-10-06 — iOS版の「使い方」にバージョンを表示し、App Storeの評価を作業の区切りで依頼する

- 影響: iOS版の「使い方」の末尾（フッター）に「バージョン 1.0（ビルド 1）」の形でバージョンとビルド番号を表示する。値はSwiftが`Info.plist`から読み、`WKUserScript`で`window.knittingEditorAppInfo`として同梱ページへ渡すので、オフラインで表示できる。「サポート」に、不具合の報告へバージョンを添えるよう一文を足した。App Storeの評価は、StoreKitのシステムの依頼画面（`AppStore.requestReview(in:)`）だけで依頼する。依頼を検討するのはPNG・PDFを「ファイルに保存」で保存し終えたとき、または共有シートで共有を終えたときだけで、初めて起動してから3日以上、前回の依頼のあとにPNG・PDFを3回以上保存・共有、同じバージョンでは一度だけ、前回の依頼から120日以上、アプリが前面にあり保存画面などが出ていない、をすべて満たすときに限る。条件は`ios/docs/NATIVE_BRIDGE.md`に書いた。「プライバシー」に、評価の依頼が出ることがあり編み図は送られない旨を足した。App Storeのレビューを書くページへのリンクは、App IDが決まっていないため置いていない（#84に残した）。Web版は変わらない（#84）。
- 主なファイル: `ios/App/AppVersionInfo.swift`、`ios/App/ReviewRequest.swift`、`ios/App/WebViewContainer.swift`、`ios/Web/public/guide/index.html`、`ios/docs/NATIVE_BRIDGE.md`、`ios/docs/WEB_SYNC.md`、`ios/knittingEditor.xcodeproj/project.pbxproj`（`xcodegen generate`で再生成）
