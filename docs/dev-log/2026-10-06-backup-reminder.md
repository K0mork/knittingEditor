# 2026-10-06 — 最後のバックアップ日時を表示し、`.knit`の書き出しを控えめに勧める

- 影響: 編み図ごとに、最後に`.knit`を書き出した日時を記録し、「保存」のバックアップ欄に「この編み図の最後のバックアップ：2026年10月6日 14:05」（未書き出しなら「この編み図はまだバックアップしていません。」）と出すようにした。「この編み図」は開いている編み図、「全データ」はその時点の全編み図の日時を記録する。ファイルを共有シート・ダウンロードへ渡した時点を書き出した日時とする（下の「レビュー後の修正」で、取りやめた場合は記録しないよう改めた）。さらに、最後の書き出し（まだなら作成）の後に変更があり、かつ書き出しから7日以上たった、または開いてから50回（なぞり描き・貼り付け・盤面設定・元に戻す／やり直すを各1回）編集したときに、道具列と盤面の間へ「この編み図はまだバックアップしていません。」／「10月4日のバックアップの後に変更があります。」の帯を1段出す。帯の「書き出す」で開いている編み図の`.knit`を書き出し、「あとで」で3日間は全編み図で出さない。盤面には重ねず、ドロワーを開いている間と処理中は出さない。帯が出ると盤面が1段下がるので、編集中は出さず、編集の手を2.5秒止めてから出す（iPhone Simulatorで、連続タップの途中に帯が出て次のタップが別の段に入ることを確かめて直した）。Web版にも同じ表示を出す。日時は設定ストアの`lastBackupAt:<編み図ID>`に置き、編み図の記録・`.knit`・DBの版は変えていないので、既存データは「まだバックアップしていない」として読める。編み図を削除すると日時の記録も消す。使い方ページ（Web・iOS）のバックアップの節に説明を1段落足した（Issue #83）。

## レビュー後の修正（2026-10-07）

- 影響:
  - なぞり描きの途中で帯が出て盤面が1段下がり、続きが別の段に入る不具合を直した。指・ポインタを画面に置いている間（1本指の描画、2本指の移動・拡大、範囲選択の途中を含む）は帯を出すまでの待ち時間を止め、すべて離してから2.5秒を数え直す。盤面に限らず画面全体の`pointerdown`・`pointerup`・`pointercancel`を見るので、盤面の部品（`BoardCanvas`）は変えていない。
  - 書き出しを取りやめても「最後のバックアップ」として記録される不具合を、Web版で直した。`EditorPlatform.saveFile`は`{ saved }`を返し、`saved`は保存・共有を終えたら`true`、取りやめたら`false`、hostが結果を返さないときは`undefined`になる。`false`のときは日時を記録せず、帯も残す。Web版のiPhone・iPadのSafariでは、確認ダイアログの「閉じる」・背景のタップ・Escapeと、共有シートの取り消し（`AbortError`）で`false`を返す。共有できずダウンロードへ切り替えたときとPCなどのダウンロードは`undefined`（不明）として、渡した時点で記録する。処理中の表示はファイルを渡し終えた時点で消し、確認ダイアログを閉じるまで出し続けない（PNG・PDFの保存の流れは変えていない）。
  - iOS版は、ネイティブの保存画面・共有シートが結果をWebへ返さないため、これまでどおり書き出しを始めた日時を記録する。Swift側の変更はPR #121が変える箇所（`finishExport`、`completionWithItemsHandler`、`cleanupPendingExport`）と重なるので、#122に分けた。iOSの使い方ページの文言を「書き出しを最後に始めた日時（保存画面を途中で閉じた場合も含みます）」に、Webの使い方ページを「iPhone・iPadで共有メニューを閉じた場合は記録しません」に改めた。
  - 「あとで」の記録を読み終えるまで「保存」のバックアップ欄に日時を出さないようにした（読み込めなかったときはこの画面では勧めを出さない）。E2Eで帯が出ないことを、待ち時間に頼らず確かめるため。
  - `ui/BackupReminder.tsx`を、中身のコンポーネント名に合わせて`ui/BackupReminderBar.tsx`へ改名した（テストも`BackupReminderBar.test.tsx`）。
