# 2026-10-06 — 最後のバックアップ日時を表示し、`.knit`の書き出しを控えめに勧める

- 影響: 編み図ごとに、最後に`.knit`を書き出した日時を記録し、「保存」のバックアップ欄に「この編み図の最後のバックアップ：2026年10月6日 14:05」（未書き出しなら「この編み図はまだバックアップしていません。」）と出すようにした。「この編み図」は開いている編み図、「全データ」はその時点の全編み図の日時を記録する。ファイルを共有シート・ダウンロードへ渡した時点を書き出した日時とする（ホストは保存を終えたかを返さないため）。さらに、最後の書き出し（まだなら作成）の後に変更があり、かつ書き出しから7日以上たった、または開いてから50回（なぞり描き・貼り付け・盤面設定・元に戻す／やり直すを各1回）編集したときに、道具列と盤面の間へ「この編み図はまだバックアップしていません。」／「10月4日のバックアップの後に変更があります。」の帯を1段出す。帯の「書き出す」で開いている編み図の`.knit`を書き出し、「あとで」で3日間は全編み図で出さない。盤面には重ねず、ドロワーを開いている間と処理中は出さない。帯が出ると盤面が1段下がるので、編集中は出さず、編集の手を2.5秒止めてから出す（iPhone Simulatorで、連続タップの途中に帯が出て次のタップが別の段に入ることを確かめて直した）。Web版にも同じ表示を出す。日時は設定ストアの`lastBackupAt:<編み図ID>`に置き、編み図の記録・`.knit`・DBの版は変えていないので、既存データは「まだバックアップしていない」として読める。編み図を削除すると日時の記録も消す。使い方ページ（Web・iOS）のバックアップの節に説明を1段落足した（Issue #83）。
