# 2026-10-08 — Web版のプライバシーポリシーとアクセス解析の告知を追加

- 影響: `https://knittingeditor.com/privacy/`を新設した（#128）。編み図が端末内（IndexedDB）にだけ保存されサーバーへ送らないことと、電気通信事業法の外部送信規律の公表事項を載せた。外部送信規律は本サイトが対象になる前提で、見出し「外部送信（Google アナリティクス）について」の下に、送信先（Google LLC）、送信される情報、利用目的を書いた。送信される情報は、ページの閲覧の情報、GA4の拡張計測（スクロール、離脱クリック、ファイルのダウンロードなど。管理画面で有効と確かめたもの）、端末・ブラウザの種類、IPアドレス、Cookieの識別子、`useEditorController.ts`が送る製品イベント11種とその付加情報。送らない情報（編み図の内容、編み図・ブロックの名前、書き出したファイル）も書いた。ほかに、Googleのポリシーとオプトアウト アドオンへのリンク、GitHub PagesがIPアドレスを記録すること、iPhone・iPadアプリは何も送らないこと（`ios/docs/PRIVACY_POLICY.md`へのリンク）、問い合わせ先（`/support/`）、制定日を載せた。編集画面では「編み図」パネルの一覧の後ろに「プライバシーポリシー（アクセス解析について）」のリンクを置いた。共通の`EditorView`に、一覧の後ろへ置く案内を受け取る`documentsNote`を足し、Web版だけがリンクを渡す。iOS版は渡さず、何も表示しない（iOS版はアクセス解析を送らない）。使い方とサポートのフッター、JavaScriptを実行する前のトップページの説明文からもリンクした。表示されない編集画面のフッターにあったGoogleのプライバシーポリシーへのリンクは`/privacy/`へ向けた。iOS版には同梱しない。
- 主なファイル: `public/privacy/index.html`、`src/App.tsx`、`packages/editor-core/ui/EditorView.tsx`、`packages/editor-core/styles/base.css`、`packages/editor-core/README.md`、`index.html`、`public/guide/index.html`、`public/support/index.html`、`public/sitemap.xml`、`scripts/check-dist.mjs`、`scripts/check-live-site.mjs`、`ios/docs/WEB_SYNC.md`
- テスト: `tests/e2e/seo.spec.ts`に、`/privacy/`を直接開いて再読み込みしても表示され、canonical・OGP・アイコンと、外部送信の見出しと公表事項（送信先・送信される情報・利用目的）、Googleのポリシーとオプトアウト アドオンへのリンクがあることを確かめるテストと、編集画面の「編み図」パネル（スマホの幅でも開いただけで見える）・使い方・サポートから`/privacy/`へ進めることを確かめるテストを足した。`packages/editor-core/ui/EditorView.test.tsx`に、`documentsNote`を渡したときだけ一覧の直後に出ることを確かめるテストを足した。JavaScriptを実行する前のトップページとサイトマップのテストに`/privacy/`を足した。`check-dist`は`privacy/index.html`の存在、og:image、アイコンを、`check-live-site`（`smoke`）は配信後の`/privacy/`を確かめる。
- 検証: 最終のコミットで`npm run typecheck`、`npm test`（34ファイル222件）、`npm run build`、`npm run check:dist`、iOS Webの型検査（`ios/Web`で`tsc -p tsconfig.app.json --noEmit`）とテスト（`vitest run --config vite.config.ts`、6ファイル23件）、`npm run test:e2e`（chromium-mobile、webkit-mobile、chromium-desktopで125件成功、既存の4件はスキップ）を実行し、すべて成功した。`dist/privacy/index.html`があり`public/privacy/index.html`と同じこと、`dist/sitemap.xml`に`/privacy/`があること、`dist/CNAME`が`knittingeditor.com`のままであることを確かめた。手元のNode.jsは26で、指定の24ではない。プライバシーポリシーを幅375pxと幅1280pxで表示し、横にはみ出さないこと（表も含む）を確かめた。「編み図」パネルのリンクも同じ2つの幅で表示し、編み図が1件のときはスクロールせずに見えることを確かめた。スマホの幅では、編み図が4件以上あるとリンクを見るのにスクロールが要る（利用者の判断で、下端には固定しない）。共通コードを変えたので、XcodeGen、SimulatorのテストとアプリのArchiveはPRのCIで確かめる（Swiftとビルド設定は変えていない）。
- デプロイ影響: Pagesへ`/privacy/`が配信され、トップページ・使い方・サポートにリンクが増える。配信後に`smoke`が`/privacy/`を確かめる。本番で`https://knittingeditor.com/privacy/`をHTTPSで直接開いて再読み込みしても表示されることを確かめる。
