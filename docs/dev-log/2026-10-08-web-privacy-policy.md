# 2026-10-08 — Web版のプライバシーポリシーとアクセス解析の告知を追加

- 影響: `https://knittingeditor.com/privacy/`を新設した（#128）。編み図が端末内（IndexedDB）にだけ保存されサーバーへ送らないことと、電気通信事業法の外部送信規律の公表事項を載せた。外部送信規律は本サイトが対象になる前提で、見出し「外部送信（Google アナリティクス）について」の下に、送信先（Google LLC）、送信される情報、利用目的を書いた。送信される情報は、ページの閲覧の情報、GA4の拡張計測（スクロール、離脱クリック、ファイルのダウンロードなど。管理画面で有効と確かめたもの）、端末・ブラウザの種類、IPアドレス、Cookieの識別子、`useEditorController.ts`が送る製品イベント11種とその付加情報。送らない情報（編み図の内容、編み図・ブロックの名前、書き出したファイル）も書いた。ほかに、Googleのポリシーとオプトアウト アドオンへのリンク、GitHub PagesがIPアドレスを記録すること、iPhone・iPadアプリは何も送らないこと（`ios/docs/PRIVACY_POLICY.md`へのリンク）、問い合わせ先（`/support/`）、制定日を載せた。使い方とサポートのフッター、JavaScriptを実行する前のトップページの説明文からリンクした。表示されない編集画面のフッターにあったGoogleのプライバシーポリシーへのリンクは`/privacy/`へ向けた。iOS版には同梱しない。
- 主なファイル: `public/privacy/index.html`、`src/App.tsx`（非表示のフッターのリンク先）、`index.html`、`public/guide/index.html`、`public/support/index.html`、`public/sitemap.xml`、`scripts/check-dist.mjs`、`scripts/check-live-site.mjs`、`ios/docs/WEB_SYNC.md`
