# 2026-10-10 — 保存失敗時の退避とバックアップ処理の改善

- 影響: #159、#162、#172、#173、#200。保存先が使えない場合も、メモリ上の盤面のコピーを個別・全データの.knitへ含める。保存失敗の表示と退避方法を表示し続ける。盤面の世代と作成時刻を捕まえ、共有中に編集・Undo・編み図の切り替えがあれば日時の記録と編集回数の解除を行わない。全データの日時は実際に含めたIDだけに記録する。個別取得は対象IDだけを読む。圧縮・解凍・JSON処理・検証はWorkerで行い、gzip入力を256バイトずつ渡して解凍上限で停止する。.knitのversion 2と既存の各上限を保つ。復元・削除・日時記録のtransaction.doneの拒否を直ちに受け取り、書き込みの元のエラーを呼び出し元へ返す。
