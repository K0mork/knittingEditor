# 2026-10-10 — 保存失敗時の退避とバックアップ処理の改善

- 影響: #159、#162、#172、#173、#200。保存先が使えない場合も、メモリ上の盤面のコピーを個別・全データの.knitへ含める。保存失敗中は見出しに「保存失敗」と出し、退避方法を伝える帯をバックアップのおすすめと同じ段・同じ見た目で出し続ける。帯の出し入れはおすすめと同じく、指を離して`BACKUP_REMINDER_IDLE_MS`待ってから行い、描いている途中に盤面をずらさない。盤面の世代と作成時刻を捕まえ、共有中に編集・Undo・編み図の切り替えがあれば日時の記録と編集回数の解除を行わない。書き出しは保存を待たないので、書き出した世代の保存が共有中に済んだときはその更新日時以上を記録し、記録の後に保存したときは記録を保存の更新日時へ進める。これにより、書き出した内容のまま自動保存されただけで次に開いたとき「バックアップの後に変更があります」と出ることはない。保存が成功した時点で、その間に新しい編集が残っていても保存失敗の表示を解除する。全データの日時は実際に含めたIDだけに記録する。個別取得は対象IDだけを読む。圧縮・解凍・JSON処理・検証はWorkerで行い、gzip入力を256バイトずつ渡して解凍上限で停止する。.knitのversion 2と既存の各上限を保つ。復元・削除・日時記録のtransaction.doneの拒否を直ちに受け取り、書き込みの元のエラーを呼び出し元へ返す。
