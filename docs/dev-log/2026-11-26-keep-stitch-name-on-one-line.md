# 2026-11-26 — 狭い画面の記号ボタンで「表目」を1文字ずつ折り返さない

- 影響: 狭い画面（759px以下）の編集ツールで、記号ボタンの記号名が「表／目」のように1文字ずつ折れていた。2026-11-04の変更（#389）で記号名を省略せず折り返すようにしたあと、ボタンの最小幅が58pxで、名前の幅が足りないまま縮んでいたため。
  - 余白と間隔を詰めるかどうかを、画面の幅ではなく、左右の安全領域を除いたツールバーの幅で決める。iPhone Duoの外側（466pt）は右にカメラとステータスバーの列（約84pt）があり、使える幅は約376ptなのに、画面幅が429pxを超えるので詰めず、既定の文字でも「表目」が2行になっていた。境目は今までと同じ（安全領域が無ければ画面幅429px以下で詰める）。
  - 貼付ボタン（ブロックをコピーすると再読み込みまで残る）が出ている間は、幅にかかわらず詰め、色の見本（30→24px）・記号の絵（32→26px）・それぞれの間隔を小さくする。これまでは既定の文字でも、iOS版の375・390・430・440ptとDuoの外側、Web版の360・430pxで「表目」が2行になり、Duoの外側ではツールバーがはみ出して文字が「描く」に重なっていた。
  - 記号名には2文字分の幅を必ず残し、ボタンはそれより縮まない。収まらないときはツールバーが横にスクロールする（iOS版で1段階大きい文字（19px）にして貼付があるときの375・390ptとDuoの外側など）。長い名前（例：裏目右上ねじり目交差）は省略せず2文字以上ずつ折り返し、1文字ずつ10行になってツールバーが200px以上の高さになることは無くなった。
  - 広い画面（760px以上）、スマホの横向き、大きな文字（ルート21px以上）の並びは変えていない。
- 主なファイル: `packages/editor-core/styles/base.css`、`packages/editor-core/ui/EditorView.tsx`
- テスト:
  - `tests/e2e/toolbar-stitch-name.spec.ts`を追加した。Web版（360〜440px）とiOS版のCSS（17pxの375〜440ptとDuoの外側）で、貼付の有無にかかわらず「表目」が1行で、記号ボタンがほかのボタンと同じ高さのまま、ツールバーがはみ出さず、右端のボタンが安全領域の手前にあることを確かめる。iOS版の19px・375pt・貼付ありでは「表目」が1行のままツールバーが横にスクロールし、貼付ボタンへスクロールできること、長い名前が2文字以上ずつ折り返すことも確かめる。変更前のコードでは、Duoの外側とWeb版360px・貼付ありで「表目」が2行になって失敗した。
  - `packages/editor-core/ui/EditorView.test.tsx`に、コピーしたブロックがある間、ツールバーに`has-paste`が付き、貼付ボタンが残ることを足した。
