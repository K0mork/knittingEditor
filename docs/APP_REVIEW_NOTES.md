# App Review notes

## Review guideline 4.2 に関する説明

本アプリは、Webサイトを表示するだけのラッパーではありません。編集エンジンはアプリバンドルへ同梱し、機内モードでも次の処理を完了できます。

- 26種類の編み目記号を使ったCanvas編集、パン、ピンチズーム
- IndexedDBへの自動保存とscene phase連動の保存flush
- PNG、1ページPDF、A4分割PDFの生成
- `.knit`バックアップの圧縮、検証、復元
- Files、AirDrop、共有シート、他アプリからの`.knit`受け入れ
- iPhoneとiPadの可変幅レイアウト、VoiceOver向けラベル、アプリ内入力ダイアログ

外部Webサイトは編集画面の起動に使いません。アプリ内ヘルプからユーザーが明示的にサポートリンクを選んだ場合だけSafariを開きます。アカウント、サーバー、広告、分析SDK、リモート設定はありません。

## 審査時の確認手順

1. 機内モードで起動する。
2. 新規編み図を作成し、複数の記号を描く。
3. アプリをバックグラウンドへ移し、戻って編集内容を確認する。
4. 保存画面からPNG、PDF、`.knit`をFilesへ保存する。
5. Filesから`.knit`を開き、復元された編み図を確認する。
6. ヘルプのプライバシー説明を開く。GitHubリンクの確認はネットワーク接続時に行う。
