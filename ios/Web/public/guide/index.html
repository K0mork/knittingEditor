棒針編み図エディタ

棒針編み図の作り方

棒針編み図エディタは、iPhoneやiPadでオフライン利用できる編み図作成アプリです。アカウント登録やネットワーク接続は必要ありません。

編み図を作成する

1. 編み目記号と色を選ぶ

画面上部の編み目記号メニューから使用する記号を選び、色を指定します。現在は26種類の編み目記号に対応しています。

2. 盤面に編み目を入力する

「描く」を選んでセルをタップまたはドラッグすると、選択中の編み目記号を連続して入力できます。「消す」では入力済みのセルを消去できます。

スマートフォンでは1本指で編集し、2本指で盤面の移動や拡大縮小を行えます。PCではマウス操作にも対応しています。

入力、消去、貼り付け、段・列の変更は、「盤面」「ブロック」「保存」の並びにある左向きの矢印（元に戻す）と右向きの矢印（やり直す）で取り消し・再実行できます。1回のなぞり入力はまとめて1回分として戻ります。キーボードを接続したiPadでは ⌘+Z で元に戻し、Shift+⌘+Z でやり直せます。履歴は開いている編み図の編集中だけ保持し、別の編み図へ切り替えたり開き直したりすると消えます。

3. 段数と列数を変更する

「盤面」から段数と列数を変更できます。上下左右への追加と削除、指定位置への段・列の挿入と削除にも対応しています。盤面は最大1000×1000セルまで扱えます。

白や薄い色の記号が盤面の地に溶けて見えにくいときは、「盤面」の「背景色」で地の色を白・グレー・黒から選ぶか、「ほかの色を選ぶ」で好きな色にできます。背景色は編み図ごとに保存され、PNG・PDFにも反映されます。

4. よく使う模様をコピーする

「範囲」で盤面の一部を選択すると、その範囲をコピーして別の場所へ貼り付けられます。繰り返し使う模様はパターンブロックとして名前を付けて保存できます。

5. PNGまたはPDFで保存する

「保存」から完成した編み図をPNGまたはPDFとして出力できます。PDFは全体を1ページに収める形式と、A4用紙へ読みやすく分割する形式を選べます。どちらも盤面の四辺に段と目の番号が入り、番号が混み合う大きな編み図では、2・5・10などの倍数だけを表示します。

6. 編み図をバックアップする

作成中のデータはアプリ専用のIndexedDBへ自動保存されます。アプリを削除すると端末内データも消えるため、重要な編み図は「保存」から .knit 形式のバックアップを書き出してください。

「保存」のバックアップ欄に、開いている編み図を最後に書き出した日時が出ます（保存の確認・「ファイルに保存」・共有を途中で取りやめた場合は記録しません）。最後の書き出し（まだなら作成）から7日以上たって変更したときや、一度に多く編集したときは、盤面の上に書き出しを勧める表示が出ます。「書き出す」でその編み図の .knit を保存し、「あとで」を押すと3日間は表示しません。

バックアップファイルは、同じエディタの「復元」から読み込めます。複数の編み図をまとめて保存することもできます。

対応している主な機能

  • 26種類の編み目記号と色指定
  • iPhoneとiPadでのタッチ操作とApple Pencil
  • 段・列の追加、挿入、削除
  • 範囲コピーとパターンブロック
  • 元に戻す・やり直す
  • PNG出力
  • 1ページPDFとA4分割PDF
  • 端末内への自動保存
  • .knit バックアップの書き出しと復元

プライバシー

編み図、記号、色、バックアップは端末内だけで処理します。アカウント、広告、アクセス解析、クラウド同期は使用しません。Safariの保存領域を読み取ることもありません。

PNGやPDFを何度か保存したあとに、App Storeでの評価をお願いするシステムの画面が表示されることがあります。評価は任意で、編み図の内容は送られません。

アプリを削除すると端末内の自動保存データも削除されます。重要なデータは`.knit`バックアップをFilesへ保存してください。
