棒針編み図の作り方

棒針編み図エディタは、iPhoneやiPadでオフライン利用できる編み図作成アプリです。アカウント登録やネットワーク接続は必要ありません。

編み図を作る前に：表側から見た記号と読み方

盤面には、編み地を表側から見た記号を置きます。右下が1段め・1目めで、段は下から上へ、目は右から左へ数えます。画面とPNG・PDFの番号も同じ向きです。

1段めを表側から編む往復編みでは、奇数段は右から左へ、偶数段は左から右へ読みます。偶数段は裏側を見て編むので、記号を読み替えます。例えば、表から見た「表目」は、裏側を見て編む段では「裏目」で編みます。メリヤス編みを描くときは、偶数段も表から見た「表目」を入力します。表と裏を自動で切り替える機能はありません。輪編みでは常に表側を見て編み、すべての段を右から左へ読みます。

作り目を盤面の1段めとして描くかどうかを、描く前に決めてください。日本の編み図では、作り目を1段めと数え、次の2段めを裏側を見て編むことがよくあります。作り目を描くと、最初に編む段は2段めになります。参考にする作品の段の数え方に合わせてください。

編み図を増やす・切り替える

画面上部の「編み図」を開き、「新しい編み図」を押して名前を入力すると、2枚目以降の編み図を作れます。一覧の編み図名を押すと、その編み図へ切り替わります。

一覧の各編み図にある「名称」で名前を変更でき、「複製」でコピーを作れます。コピーを編集するには、一覧からその編み図を選びます。「削除」は確認後に編み図を削除します。削除は元に戻せないので、必要なら先にバックアップしてください。編み図が1枚だけのときは削除できません。

1. 編み目記号と色を選ぶ

画面上部の編み目記号メニューから使用する記号を選び、色を指定します。現在は26種類の編み目記号に対応しています。

2. 盤面に編み目を入力する

「描く」を選んでセルをタップまたはドラッグすると、選択中の編み目記号を連続して入力できます。「消す」では入力済みのセルを消去できます。「白くする」はセルを白で塗る記号で、選んだ色にかかわらず白く描かれます。記号を消して盤面の背景色に戻すには「消す」を使います。

iPhone・iPadでは1本指で編集し、2本指で盤面の移動や拡大縮小を行えます。マウスやトラックパッドを接続したiPadでも操作できます。

入力、消去、貼り付け、段・列の変更は、「盤面」「ブロック」「保存」の並びにある左向きの矢印（元に戻す）と右向きの矢印（やり直す）で取り消し・再実行できます。1回のなぞり入力はまとめて1回分として戻ります。キーボードを接続したiPadでは ⌘+Z で元に戻し、Shift+⌘+Z でやり直せます。履歴は開いている編み図の編集中だけ保持し、別の編み図へ切り替えたり開き直したりすると消えます。

3. 段数と列数を変更する

「盤面」から段数と列数を変更できます。上下左右への追加と削除、指定位置への段・列の挿入と削除にも対応しています。盤面は最大1000×1000セルまで扱えます。

白や薄い色の記号が盤面の地に溶けて見えにくいときは、「盤面」の「背景色」で地の色を白・グレー・黒から選ぶか、「ほかの色を選ぶ」で好きな色にできます。背景色は編み図ごとに保存され、PNG・PDFにも反映されます。

4. よく使う模様をコピーする

「範囲」を選び、盤面をドラッグして模様を囲みます。「コピーして貼付」を押してから貼り付け先をタップすると、保存せずに別の場所へ貼り付けられます。繰り返し使う模様は、範囲を選んだまま「ブロック」を開き、「選択範囲をブロック保存」を押して名前を入力します。

保存した模様を使うには、「ブロック」を開いて保存済みブロックの名前を選び、盤面の貼り付け先をタップします。ブロック全体が盤面に収まる場所を選んでください。別の編み図でも同じブロックを使えます。

5. PNGまたはPDFで保存する

「保存」を開き、「PNGを保存」または「PDFを保存」を押して出力します。PDFは全体を1ページに収める形式と、A4用紙へ読みやすく分割する形式を選べます。どちらも盤面の四辺に段と目の番号が入り、番号が混み合う大きな編み図では、2・5・10などの倍数だけを表示します。

出力すると「ファイルを保存」の確認が表示されます。「ファイルに保存」を選ぶと、保存先を指定して「ファイル」アプリへ保存できます。「共有」を選ぶと共有メニューが開きます。プリントの項目が表示される環境では、そこから印刷できます。バックアップを書き出したときも、同じ確認から保存または共有を選びます。

6. 編み図をバックアップする

作成中のデータはアプリ専用のIndexedDBへ自動保存されます。アプリを削除すると端末内データも消えるため、重要な編み図は「保存」から .knit 形式のバックアップを書き出してください。

「保存」のバックアップ欄に、開いている編み図を最後に書き出した日時が出ます（保存の確認・「ファイルに保存」・共有を途中で取りやめた場合は記録しません）。最後の書き出し（まだなら作成）から7日以上たって変更したときや、一度に多く編集したときは、盤面の上に書き出しを勧める表示が出ます。「書き出す」でその編み図の .knit を保存し、「あとで」を押すと3日間は表示しません。

「保存」のバックアップ欄で「この編み図」を押すと、開いている編み図だけを書き出します。保存済みブロックは含まれません。「全データ」はすべての編み図と保存済みブロックをまとめて書き出します。ブロックも別の端末へ移す場合は「全データ」を選んでください。編み図を1枚ずつ書き出しても、ブロックは移せません。

読み込むには「保存」の「復元」を押し、.knit ファイルを選びます。既存の編み図は上書きされず、名前に「（復元）」を付けた別の編み図として追加され、復元した先頭の編み図へ切り替わります。「全データ」のバックアップなら、保存済みブロックも追加されます。

対応している主な機能

  • 26種類の編み目記号と色指定
  • iPhoneとiPadでのタッチ操作とApple Pencil
  • 段・列の追加、挿入、削除
  • 範囲コピーとパターンブロック
  • 元に戻す・やり直す
  • PNG出力
  • 1ページPDFとA4分割PDF
  • 端末内への自動保存
  • .knit バックアップの書き出しと復元

プライバシー

編み図、記号、色、バックアップは端末内だけで処理します。アカウント、広告、アクセス解析、クラウド同期は使用しません。Safariの保存領域を読み取ることもありません。

PNGやPDFを何度か保存したあとに、App Storeでの評価をお願いするシステムの画面が表示されることがあります。評価は任意で、編み図の内容は送られません。

アプリを削除すると端末内の自動保存データも削除されます。重要なデータは .knit バックアップを「ファイル」アプリへ保存してください。
